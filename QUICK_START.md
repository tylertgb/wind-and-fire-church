# Quick Start Guide - Wind & Fire Church Website

## 🚀 Get Up and Running in 3 Steps

### **Step 1: Install Dependencies**
```bash
pnpm install
# or
npm install
```

### **Step 2: Run Development Server**
```bash
pnpm dev
# or
npm run dev
```

### **Step 3: Open Browser**
Navigate to: **http://localhost:3000**
